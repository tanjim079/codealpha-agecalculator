# 🌌 Aesthetic Age Calculator

A modern and aesthetic Age Calculator web application built using **HTML**, **CSS**, and **JavaScript**.

This project features:
- ✨ Bluish charcoal glassmorphism UI
- 🎨 Fancy typography
- 📅 Age calculation from Date of Birth to any custom date
- ⚡ Real-time accurate age calculation
- 📱 Fully responsive design

---

# 🚀 Features

- Calculate exact age in:
  - Years
  - Months
  - Days

- Default calculation date is today's date
- User can select any custom target date
- Professional and aesthetic UI design
- Responsive layout for mobile and desktop

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts
